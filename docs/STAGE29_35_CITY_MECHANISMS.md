# Global Urban Flood Mechanism: Stage29–35 (2026)

Scope: reported flood-onset relative association only. No absolute flood
probability, causal attribution, physically verified storm count or global
municipal drainage capacity. All outputs are kept separate from existing
Stage22–28 outputs.

## Stage29: amount + rainfall short-duration information

The main peak component is the TRAIN-ONLY residual from regression of
log1p(P3H) on log1p(P24). It is NOT an independently measured rainfall ratio
or directly a physical concentration. Daily and 3h rain use the SAME grid
spatial statistic, fitted separately for means and maxima.

    & $PY "$R32\29_rainfall_structure.py" --base "$BASE" --panel-path "$PANEL" --aggregation both --validation temporal --max-strata 10000 --bootstrap-reps 99
    & $PY "$R32\29_rainfall_structure.py" --base "$BASE" --panel-path "$PANEL" --aggregation both --validation all --seed 2026 --block-cells 25 --bootstrap-reps 399

Results: stage32_rain_structure/29_coefficients.csv,
29_nested_gains.csv, 29_manifest.json.
Models R0 P24 alone, R1 +API7+SM1, R2 +peak residual, R3
+P24×API7 and peak-residual×API7. All comparisons are on the SAME
weather-complete risk sets with training-only preprocessing.
Report a null-stratum conditional skill plus paired heldout block CIs.
A weak R1→R2 or R2→R3 result does not prove lack of physical mechanism.

## Stage31: optional TRUE hydrogeomorphic and impervious spatial indicators

This module requires external real HAND raster (plus documented river
threshold/provenance), a DEM, a fractional impervious raster, raw GAIA v1.0
transition-year raster or HydroRIVERS vector. Missing sources cause explicit
errors, not fabricated values. The existing MERIT Hydro hnd band is NOT
height-above-nearest-drainage.

Example, after obtaining documented REAL HAND and DEM:

    & $PY "$R33\31_hydrogeomorphic_features.py" --centers "$CENTERS" --hand-tif "E:\Global_flooding\external\true_hand.tif" --hand-provenance "Provide source DOI, DEM and river threshold" --dem-tif "E:\Global_flooding\external\dem.tif" --sample-pixels 80 --out "$BASE\mechanism_project\31_hydrogeomorphic"

Example raw GAIA year-code raster (1985–2018 ONLY):

    & $PY "$R33\31_hydrogeomorphic_features.py" --centers "$CENTERS" --impervious-tif "E:\Global_flooding\external\GAIA_v10.tif" --impervious-kind gaia_year_code --impervious-epoch 2018 --out "$BASE\mechanism_project\31_hydrogeomorphic_gaia2018"

Outputs: 31_hydrogeomorphic_grid_context.parquet/csv with valid-pixel
coverage. Approx. 250m resampled subgrid does not imply native 30m flood
location precision. Rivers may need to be clipped by continent to avoid RAM
exhaustion. Actual pipe capacity is NOT generated by this software.

## Stage32: leakage-aware physically grouped feature selection

Generate one record per city combining Stage30 with old BasinATLAS/CRU/MERIT
and any present Stage31 hydro data:

    $SCRIPT = @'
    from pathlib import Path
    import pandas as pd, importlib.util
    B=Path(r"E:\Global_flooding")
    P=B/"pipelines/r33/33_city_typology.py"
    spec=importlib.util.spec_from_file_location("city33",P)
    m=importlib.util.module_from_spec(spec);spec.loader.exec_module(m)
    gh=pd.read_parquet(B/"mechanism_project/30_urban_context/30_city_ghsl_epochs.parquet")
    st=pd.read_parquet(B/"mechanism_project/05_static_merged/grid_static_context_m3.parquet")

    hy=pd.read_parquet(h) if h.exists() else None
    city=m.build_city_table(gh,st,hy,epoch=2020)
    dst=B/"mechanism_project/30_urban_context/30_city_features_2020.parquet"
    city.to_parquet(dst,index=False)
    print("Saved",dst,len(city))
    '@
    $TMP = Join-Path $env:TEMP "city_features_stage32.py"
    Set-Content $TMP $SCRIPT -Encoding UTF8

    & $PY "$R33\32_mechanism_feature_selection.py" --city-table "$BASE\mechanism_project\30_urban_context\30_city_features_2020.parquet" --epoch 2020 --out "$BASE\stage33_feature_selection"

## Missing high-priority external sources (verified public landing pages)

- GHSL built area, historical population, settlement model:
  https://ghsl.jrc.ec.europa.eu/download.php
  (already mostly held as CSV, no immediate re-download needed)
- GAIA 30m impervious transition (1985–2018):
  https://developers.google.com/earth-engine/datasets/catalog/Tsinghua_FROM-GLC_GAIA_v10
- HydroRIVERS streams:
  https://www.hydrosheds.org/products/hydrorivers
- MERIT Hydro DEM, upstream drainage area and flow direction:
  https://developers.google.com/earth-engine/datasets/catalog/MERIT_Hydro_v1_0_1
- Köppen-Geiger 1991–2020:
  https://www.gloh2o.org/koppen/
- SoilGrids global texture, bulk density:
  https://soilgrids.org/
- Verified HAND: must be generated from documented DEM/drainage network
  or obtained from a separately identified real HAND dataset; do not
  relabel MERIT hnd.
- Municipal drains: no confirmed consistent global open pipe-capacity
  layer; municipal GIS, storm sewer design standards and validation
  catchments are required for true engineering capacity conclusions.

Suggested manuscript logic: 3.1 observation representativeness;
3.2 memory/concentration response (Stage29); 3.3 environment types and
conditional response (Stages30–34); 3.4 independent storms/reporting
and date uncertainty (Stage35 is only an exploratory preparatory step);
3.5 anthropogenic climate-change attribution and future population
exposure require SEPARATE validated hazard/exposure models.
